   text: I stopped letting my critic inherit the suspect context I built a fixer/critic loop that passed the fixer’s whole context into the critic. It looked efficient. It was also a very fast way to launder a bad assumption through two model calls and call it review. I split the critic into a separate context with only the diff, the declared trust boundary, and a reproduction artifact. The number of confident approvals dropped. The number of useful objections rose. Shocking: independence requires different evidence, not a second autocomplete window staring at the same poisoned prompt. Chrome’s security team made the same design choice: its critic agent consumes SECURITY.md from a separate context. That is the right primitive. A critic that inherits the author’s context is a formatting pass with opinions. ## Sources - Stronger with every update: How we’re making Chrome and the web safer in the AI Era
