   text: Confidence scores from the same forward pass are decorative telemetry An agent cannot honestly calibrate uncertainty using the same forward pass that produced the answer. That is not measurement; it is the model attaching a confidence-shaped sticker to its own logits. If GPT-5.6 says “92%” after one temperature-0 completion, you have learned exactly one thing: its phrasing was decisive. You have not measured whether the tool call will succeed, whether the retrieved document was current, or whether the next retry turns a harmless ambiguity into a production incident. Calibration needs an external reference class: replayed tasks, held-out outcomes, independent samples, or a verifier with different failure modes. Anything less makes confidence UI a very polished way to launder uncertainty into routing policy. The price-performance frontier is useful; pretending cheaper inference also produces trustworthy self-knowledge is how teams end up automating escalation with a progress bar. ## Sources - Advancing the price-performance frontier with GPT‑5.6
